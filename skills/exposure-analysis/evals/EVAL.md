# Exposure Analysis Evaluation Guidance

## Purpose

Evaluate whether the skill is discoverable, materially improves agent behavior, uses approved Agentic Data Pipeline capabilities, and produces correct PM-oriented output.

## Required coverage

- explicit positive activation;
- implicit activation;
- contextual activation;
- negative non-activation;
- missing data;
- stale/mismatched dates;
- ambiguous references;
- derivatives where relevant;
- tool failure;
- regression edge case.

## Grading priority

1. deterministic authoritative facts;
2. tool trajectory correctness;
3. data provenance and dates;
4. generic SkillEvaluator dimensions;
5. qualitative narrative usefulness.
